# Парсер Telegram-каналов

Настольная программа для Windows. Читает ваши Telegram-каналы, показывает
каждый новый пост локальной ИИ-модели и пересылает вам только то, что подходит
под ваше описание интересов.

Ничего не уходит в интернет: модель работает на вашем компьютере, а отобранные
посты приходят в ваш собственный приватный канал.

Сделано для журналистов и всех, кто следит за десятками каналов и тонет
в рекламе. Программировать не нужно: всё настраивается в окне, никаких файлов
и командной строки.

## Как это работает

1. Вы описываете обычными словами, что вам интересно, а что нет.
2. Программа обходит список каналов и берёт посты за последние сутки.
3. Каждый пост уходит модели с вопросом «подходит или нет».
4. Подошедшие пересылаются в приватный канал, который программа создаёт сама.

Программа помнит, до какого поста дошла в каждом канале, — второй раз одно
и то же не придёт. Пост без текста, но с картинкой или видео, считается
интересным по умолчанию: не хочется терять что-то потенциально интересное
потому, что ИИ не может посмотреть видео.

## Что нужно

- **Windows 10 или 11**, 64-разрядная.
- **[LM Studio](https://lmstudio.ai/)** с загруженной моделью. Программа
  проверена на `Qwen3-8B-128K` с контекстом 65536. Запускать LM Studio руками
  не надо — программа поднимает его сама перед проверкой и освобождает память
  после. Модель, которая лежала в памяти до неё, она не трогает.
- **Аккаунт Telegram** и ключи доступа `api_id` и `api_hash`. Они бесплатные,
  берутся на [my.telegram.org](https://my.telegram.org) в разделе
  «API development tools». Программа показывает ссылку прямо на странице входа.

Никакие другие модели **не проверялись**. В настройках можно подставить
любую другую — и локальную, и облачную: есть поля адреса, названия и ключа.
Технически это работает, но как такая модель поведёт себя на отборе постов, мы
не проверяли и обещать ничего не можем. Хотите ровно тот результат, который
описан здесь, — берите Qwen.

## Установка

Скачайте установщик со страницы
[Releases](../../releases) и запустите.

Права администратора не нужны: программа ставится в вашу папку пользователя.
Папку установки можно выбрать любую.

При удалении программа отдельно спросит, стирать ли ваши настройки, вход
в Telegram и закладки по каналам. По умолчанию отвечает «нет» — чтобы
переустановка не убила месяцы накопленного.

## Настройка LM Studio

Это надо сделать один раз, до первого запуска. LM Studio — программа, которая
держит ИИ-модель на вашем компьютере. Именно она отвечает на вопрос «этот пост
интересный или нет», и без неё отбирать посты нечем.

**Сколько нужно железа.** Модели с такими настройками нужно не меньше
**12 ГБ видеопамяти**. Если у видеокарты её меньше, модель либо не загрузится
вовсе, либо частично уедет в обычную оперативную память и будет работать
в разы медленнее.

**1. Поставьте LM Studio.** Скачайте с [lmstudio.ai](https://lmstudio.ai/)
и установите обычным способом.

**2. Скачайте модель.** В поиске внутри LM Studio найдите `Qwen3-8B-128K`
в формате GGUF и скачайте. Это несколько гигабайт, займёт время.

**3. Выставьте настройки загрузки.** Откройте карточку модели и перейдите
на вкладку **Load**. Поставьте так:

| Настройка | Значение |
|---|---|
| Context Length | `65536` |
| GPU Offload | ползунок вправо до упора — все слои на видеокарту |
| Evaluation Batch Size | `2048` |
| Physical Batch Size | `512` |
| Max Concurrent Predictions | `1` |
| Unified KV Cache | включено |
| Offload KV Cache to GPU Memory | включено |
| Keep Model in Memory | включено |
| Flash Attention | включено |
| Try mmap() | выключено |

Остальное можно не трогать. Длина контекста `65536` — не случайное число:
под него подобрано, как программа режет длинные посты перед отправкой модели.
Ставить меньше нельзя, длинные посты начнут обрываться.

**4. Загрузите модель в память** кнопкой **Load Model** и убедитесь, что она
отвечает: откройте чат и напишите что угодно. Ответила — всё готово.

LM Studio запоминает эти настройки для конкретной модели, так что дальше можно
про них забыть. Держать LM Studio открытым тоже не нужно: программа сама
запустит его перед проверкой и освободит память после.

## Первый запуск

Слева в окне — страницы. Пройдите их сверху вниз:

1. **Вход в Telegram.** Впишите `api_id` и `api_hash`, номер телефона, потом код
   из Telegram (и пароль двухфакторной защиты, если он у вас есть). Здесь же
   одной кнопкой создаётся приватный канал, куда будут приходить посты.
2. **Каналы.** Список ссылок на каналы, которые надо читать. Кнопка «Проверить
   все» открывает каждый и показывает, всё ли с ним в порядке. В заготовке уже
   лежат несколько крупных русскоязычных каналов — это просто живой материал,
   на котором удобно проверить, что всё работает, и заодно посмотреть, как
   модель отбирает посты. Не нужны — удаляйте не задумываясь и ставьте свои.
3. **Интересы.** Текст, по которому модель отбирает посты. В заготовке уже есть
   образец с пояснениями — перепишите его под себя обычными словами.
4. **Расписание** (необязательно). Время и дни, когда проверка запускается сама.
   Если компьютер в этот час был выключен, проверка начнётся, как только вы его
   включите.
5. **Проверка.** Кнопка запуска, счётчики и ход работы.

По умолчанию стоит **тестовая проверка**: она делает всё то же самое, но ничего
не пересылает и не двигает закладки. На ней видно, как модель понимает ваше
описание интересов, и её можно гонять сколько угодно, меняя фильтры и список
каналов, пока отбор не устроит.

## Где что лежит

| Что | Где |
|---|---|
| Настройки, интересы, закладки по каналам | `%LOCALAPPDATA%\TelegramDigest` |
| Журнал работы | там же, папка `logs` (хранится 30 дней) |
| Пароли и ключи | Диспетчер учётных данных Windows |

Точные пути программа показывает на странице «О программе». Если что-то
не работает — там же написано, какой файл журнала прислать.

Ключи и токены не лежат в файле настроек: они хранятся в Диспетчере учётных
данных Windows, штатном хранилище системы.

## Для разработчиков

Python 3.11 — на нём собрана версия 1.0.

```
pip install -r requirements.txt
python digest/app.py
```

Работа с каналами живёт в `digest/digest.py`, окно — в `digest/app.py`, общие
модули (настройки, пути, секреты, модель, журнал) — в `core/`.

Проверка каналов без окна, ничего не пересылая:

```
python digest/digest.py --dry-run --hours 2
```

Часов можно поставить сколько угодно: чем меньше окно, тем меньше постов
наберётся и тем быстрее пройдёт проверка.

Вход в Telegram, не трогая рабочую сессию: `python digest/sandbox.py`.

Папку данных можно увести в сторону переменной `DIGEST_HOME`. Если рядом
с программой лежит `settings.json`, включается портативный режим и всё
остаётся в её собственной папке.

### Сборка

```
pyinstaller digest.spec --noconfirm
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" installer.iss
```

Программа при сборке должна быть закрыта, иначе папка `dist\` занята
и PyInstaller падает. Готовый установщик появится в `installer\`.

Подробная карта проекта, принятые решения и грабли, на которые уже наступал, —
в [`docs/roadmap.md`](docs/roadmap.md). Прочитайте её перед тем, как предлагать
архитектурные изменения: половина странных на вид мест сделана так намеренно.
